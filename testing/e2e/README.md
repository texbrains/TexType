# End-to-end kits

**Owns**

- end-to-end runs that no single host owns: across the app and several hosts, and through the door for AI agents

**Limits**

- a host's own tests in its real application are in `hosts/windows/tests` and `hosts/macos/tests`
- they test through the same doors users and agents use; no private back doors into the add-ins
