# Word and PowerPoint add-ins (VBA)

**Owns**

- `word`, `powerpoint` and `shared` module sources of the add-in files
- the build of the add-in files from these sources

**Limits**

- a module does object-model work for one area (insert, numbering, pictures, ...); it decides nothing the Windows add-in also decides
