# macOS add-ins

**Owns**

- everything that runs inside Word, PowerPoint and WPS on macOS

**Limits**

- object-model calls only: rules and conversions come from the app
- no settings of its own

Folders: `office-vba` (Word and PowerPoint add-in sources), `wps-js` (WPS add-in, TypeScript compiled to JavaScript), `tests`.

First version of this code: see `docs/SOURCES.md`.
